# Raian PK Archive — code and render files

Files moved out of the Claude project knowledge (PK) on November 16, 2026, under NCH 6. Each file name starts with its call number; the abstracts are in the project's `claude/PK Archive Register`. This branch (`pk-archive`) is kept off `main` so nothing here is published on GitHub Pages until Doug chooses.

- `models/` — Three.js pages: V.7 *Seven Toroidal Centers* (not yet public), V.9 triquetra/violet sphere.
- `renders/` — V.8 the energy-center 3D render source, its toolkit (V.8a) and six render/chart fold-ins (V.8b–g). Needed only if a render is revised; the fold-ins carry code meant to be spliced into V.8.
- `svg/` — Law of Three diagrams (K.3 GAR, K.4 Zeir Anpin), YHWH on the Tree (K.5), early toroidal diagrams (V.1, V.2).
- `scripts/` — W.5 the Creator-as-Tree slide script.

Live models already on `main` (served on Pages): `index.html` (poloidal core, V.6), `sun.html` (V.4), `saturn.html` (V.5), `primary-tree.html` (V.10, active work), plus `green-ray.html`, `temple.html`, `knife-target.html`.
